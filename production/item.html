One-time setup: your GitHub key

Saving needs a key from GitHub — a long secret code, like a spare key that only opens one door: your Hearth inventory. You make it, you paste it here once, it stays saved in this browser on your phone. Dude never sees it, and you can throw it away anytime.

  1. On github.com, tap your picture (top right) → Settings.
  2. Scroll the left menu to the very bottom → Developer settings.
  3. Personal access tokens → Fine-grained tokens → Generate new token.
  4. Name it hearth-inventory. Set expiration to 1 year.
  5. Under Repository access choose Only select repositories → pick mogollon-s-hearth-build-page.
  6. Under Permissions → Repository permissions → Contents → Read and write.
  7. Generate token, then copy the code it shows.
