# Build notes — Hearth build page check

- `build/hearth_publish_check.py` — checks, after a publish, that the Hearth build page and its pieces stand live as built. It runs on Muse's side as part of the batch job set; it reads the published page and compares it against the build record.
- `build/hearth-prop-inventory.md` — the standing Hearth prop inventory: every prop on hand for Mogollon's Hearth, numbered, with its picture record. The inventory work and its pages rest on this list.
